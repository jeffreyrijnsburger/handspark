# README demo provenance

`demo-person.png` is an entirely synthetic person and room, generated with the
built-in image_gen tool on 2026-10-20. No real webcam capture or meeting is used.

Generation prompt:

> Use case: photorealistic-natural. Create a deliberately cheesy webcam demo photo for an open-source video-call reactions app. A fictional cheerful adult man in a home office, facing the camera with an exuberant rock-star grin, wearing a headset and an amusing bright patterned shirt. Both hands raised beside his head, entirely visible: each makes the exact metal-horns gesture, index finger and pinky extended, middle and ring fingers folded, thumb folded over the curled fingers. Realistic anatomy, exactly five fingers per hand. Centered waist-up wide 16:9 composition, hands and head separated, visible forearms, plain uncluttered office background, clean natural webcam lighting, face and hands sharp. The man and room are wholly synthetic. Absolutely no lasers, glows, effects, UI, text, logos or watermarks; the application will add its actual laser effect afterward.

`demo-frame.png` uses a frame decoded at 2.2 seconds from the app's actual
`reactions-apple/lasers.mov`. Its person mask uses the same MediaPipe model,
tracked hand preservation and `soften_person` function as the runtime. The
layer order matches the application's background effect and foreground camera.
The lasers are not invented or painted by the image generator.

`handspark-demo.png` is captured from the real native Qt `Panel`, with that
synthetic composite as its preview. It is an illustrative application screenshot,
not a live Teams call or a photograph of a real user. The CLI/camera service is
not started or modified while capturing it. No GUI layout is generated by AI.

Rebuild after preparing the assets:

```sh
.venv/bin/python tools/create_demo.py
```

`lasers-preview.gif` is a procedural animated effect preview with a simple
synthetic silhouette. The README labels both demonstrations as synthetic.
